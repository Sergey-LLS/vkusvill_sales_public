# ВкусВилл: скидки с доставкой — как развернуть у себя

Версия 2.10.4-public.1 (28 сентября 2026) — публичная копия версии 2.10.4: тот же
код и те же инструкции, без личных данных и без режима магазина.

Проект для Claude Code. По просьбе «что сегодня выгодного» он собирает все
скидки вашего аккаунта ВкусВилла на ваш адрес доставки и отдаёт отчёт; умеет
разложить список по выгоде и положить выбранное в корзину. Заказ и оплату
делаете только вы.

Подробно, как всё устроено, — [dostavka/README.md](dostavka/README.md).

**Только macOS, Google Chrome и Claude Code.** На Windows и Linux не
проверялся. В Codex и других агентах без адаптации не заработает — что
менять, в разделе «Если у вас Codex» ниже.

## Что нужно

1. **Claude Code** — приложение Claude (вкладка Code) или `claude` в терминале.
   Вход через `/login`, подписка Pro, Max, Team или Enterprise (с ключом API
   браузер не работает), доступ к моделям Opus и Sonnet. Режим разрешений —
   **автоматический**. В терминальной версии включите браузер: `/chrome` →
   «Enabled by default».
2. **Google Chrome** (скачать: https://www.google.com/chrome/, основным
   делать не нужно; Safari не подходит) с расширением **Claude in Chrome**
   (https://chromewebstore.google.com/detail/fcoeoabgfenejglbffodgkkbkcdhcgfn),
   в расширении выполнен вход в ваш аккаунт Claude.
3. **Вход на vkusvill.ru** в этом Chrome (номер телефона и код из SMS — сами)
   и **выбранный адрес доставки** на сайте.
4. **Python 3.** На новом Mac при первом запуске macOS может предложить
   установить инструменты разработчика — согласитесь, это несколько минут.
   Node.js нужен, только если будете править код для страницы (`build.py`
   пересобирает копии).
5. **Загрузки Chrome без вопросов.** Данные для отчёта Chrome сохраняет файлом
   в папку «Загрузки». Если в настройках Chrome включено «Всегда указывать
   место для скачивания» или выбрана другая папка, отчёт не соберётся.

Ключи, токены и сторонние сервисы не нужны. MCP-сервер ВкусВилла официальный,
без авторизации.

## Как развернуть

1. Положите эту папку куда удобно, например в `~/Documents/Claude/`.
2. Откройте в Claude Code новую сессию **именно в этой папке** (там, где лежит
   `CLAUDE.md`). В другой папке скилла и исполнителя не будет.
3. При первом запуске Claude Code спросит, подключать ли MCP-сервер
   `vkusvill` из `.mcp.json`, — одобрите.
4. Напишите: «что сегодня выгодного с доставкой».

На первое же сообщение (хоть «привет») агент ответит коротко: что умеет,
что нужно и какие пять шагов сделать. Сделайте их и напишите «готово» — агент
проверит подключение и напишет «Всё, мы готовы к работе». Дальше скажите «что
сегодня выгодного».

Первый вопрос в работе — только товары ВкусВилла или все, включая
партнёрские. Адрес агент берёт тот, что выбран у вас на сайте. Потом агент откроет **отдельное окно Chrome** — разверните его на весь экран и
не трогайте, пока в чате не придёт итог (6–7 минут). Другими окнами Chrome
пользоваться можно. Если окно узкое, агент остановится и попросит его
развернуть.

**Если расширение перестало открывать сайты** («Could not verify this site's
safety category»), агент остановится и скажет. Помогает подождать пару минут
или выйти и снова войти в расширение.

**Два компьютера под одним аккаунтом Claude.** Расширение подключается к
аккаунту Claude, а не к компьютеру: сессия на одном компьютере может попасть
в Chrome на другом. Работая на одном, закройте Chrome на другом.

После отчёта можно сказать «разложи по выгоде» или «положи в корзину …» и
перечислить товары словами.

## Если у вас Codex (или другой агент)

Проект можно перенести, но это **не проверено**: всё ниже — план адаптации, а
не готовая инструкция. Каждый шаг проверять на настоящем сайте, по одному.

| Что в Claude Code | Что сделать в Codex |
|---|---|
| Инструкции проекта в `CLAUDE.md` | Codex читает `AGENTS.md`. Когда адаптация готова, заменить текущий `AGENTS.md` (сейчас в нём предупреждение «не запускать») указателем на `CLAUDE.md` и `SKILL.md` плюс отличиями для Codex |
| Скилл `.claude/skills/vkusvill-dostavka/SKILL.md` подключается сам | Попросить агента прочитать этот файл напрямую или сослаться на него из `AGENTS.md` |
| MCP ВкусВилла в `.mcp.json` | Подключить тот же сервер `https://mcp.vkusvill.ru/mcp` (без авторизации) в настройках Codex — формат по его документации |
| Браузер: расширение Claude in Chrome | **Главное.** Нужен инструмент, который управляет Chrome и умеет выполнять код в открытой странице, — например, MCP для браузера (Playwright, Chrome DevTools). «6 скидок» с 2.10 идут запросами из кода, клики нужны только в корзине. Вход на vkusvill.ru нужен в том браузере или профиле, которым он управляет |
| Исполнитель на Sonnet (`.claude/agents/…`) | Такого механизма нет — сбор ведёт сама сессия. Шаги сбора брать из файла исполнителя: он написан как пошаговая инструкция |
| Код в страницу — только печатью целиком (ограничение Claude Code) | У другого инструмента свои правила: возможно, код можно подключать проще. Выяснять на месте |

**Работает без изменений:** код для страницы (`scripts.min.js`,
`cart-kit.js`), сборка отчёта `make_report.py`, список по выгоде
`vygoda.py` — это обычный JavaScript и Python. Справочник по сайту
`obshchee/spravochnik.md` тоже годится как есть.

**С чего начать проверку:** вставить `cart-kit.js` на странице корзины и
получить ответ `check: ok` — значит, браузерный инструмент подходит. Дальше —
по шагам исполнителя, после каждого сверяясь, что фильтры аккаунта и корзина
не изменились.

Запреты те же в любом агенте: не оформлять и не оплачивать заказ, не вводить
телефон, код из SMS и данные карты, не менять настройки аккаунта.
