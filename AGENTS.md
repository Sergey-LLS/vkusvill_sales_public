# Для агентов, кроме Claude Code (Codex и другие)

**Этот проект сделан для Claude Code и расширения Claude in Chrome. В другом
агенте он без адаптации работать не будет.** Не запускай сбор скидок по
файлам проекта как есть: скажи пользователю то, что написано ниже. Если он
попросит адаптировать проект под тебя — план в `dostavka/README.md`, раздел «Если
у вас Codex»; проверяй каждый шаг на сайте по одному.

Почему не будет работать:

- **Браузер.** Весь сбор идёт через расширение Claude in Chrome (оно привязано
  к аккаунту Claude): код печатается в открытую страницу vkusvill.ru, там же
  идут запросы «6 скидок» и раскладывается корзина. Без этого расширения
  нужен другой способ управлять браузером, и все шаги придётся заново
  проверить на настоящем сайте.
- **Исполнитель.** Сбор делает субагент Claude Code на модели Sonnet
  (`.claude/agents/vkusvill-sborshik-dostavka.md`) — такого механизма и этой
  модели в другом агенте нет.
- **Правила.** Они в `CLAUDE.md` и в скилле
  `.claude/skills/vkusvill-dostavka/SKILL.md`, который Claude Code подключает
  сам. Многие решения там — обход ограничений именно Claude Code (например,
  код в страницу только печатью целиком); у другого агента ограничения свои.
- **MCP ВкусВилла** подключён через `.mcp.json` — формат Claude Code. Сам
  сервер (`https://mcp.vkusvill.ru/mcp`, без авторизации) другой агент может
  подключить в своих настройках: он даёт состав, КБЖУ, рецепты, аналоги и
  магазины, но не знает адреса, остатков и персональных скидок.

Что можно предложить пользователю:

1. Открыть эту папку в **Claude Code** — что нужно, написано в `dostavka/README.md`.
2. Или адаптировать проект под этот агент и его способ управлять браузером —
   по плану в `dostavka/README.md` (раздел «Если у вас Codex»), с проверкой каждого шага на настоящем сайте. Без
   такой проверки полный сбор не запускать: он ходит по аккаунту пользователя.

Что нельзя никогда, в любом агенте: оформлять и оплачивать заказ, вводить
телефон, код из SMS и данные карты, менять настройки аккаунта ВкусВилла.
