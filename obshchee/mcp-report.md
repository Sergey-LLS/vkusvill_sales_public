# Отчёт: официальный MCP-сервер ВкусВилла

Проверено 19–22.09.2026. Сервер `https://mcp.vkusvill.ru/mcp`, «VV MCP Server» 0.0.1,
протокол MCP 2025-03-26, HTTP-транспорт. Источник — статья в блоге ВкусВилла на Хабре
(30.12.2025, habr.com/ru/companies/vkusvill/articles/981866/).

## Безопасность

- Домен и сертификат официальные: `*.vkusvill.ru`, GlobalSign, «JSC VKUSVILL».
- Стоит за Qrator (защита от DDoS), как и основной сайт.
- Авторизации нет, кода на машину не ставит, аккаунта не видит, заказать и оплатить
  ничего не может. Подсказок-инструкций для ИИ в описаниях инструментов нет.
- Получает только поисковые запросы и список товаров для корзины.

## Инструменты (8)

| Инструмент | Что даёт |
|---|---|
| `vkusvill_products_search` | поиск, 10 на страницу, сортировка, фильтр «только бренд ВкусВилл» (`vvonly`, по умолчанию 1!), поля по выбору |
| `vkusvill_product_details` | состав, КБЖУ, цена, рейтинг по id |
| `vkusvill_product_barcode` | то же по штрихкоду EAN-13 |
| `vkusvill_product_analogs` | до ~16 замен с ценой и составом |
| `vkusvill_products_discount` | скидки двух типов: `card` (по карте) и `quantity` (от N шт), по всей сети |
| `vkusvill_shops` | магазины: адрес, координаты, часы, особенности; фильтры по региону, городу, метро, особенности |
| `vkusvill_recipes` | ~2 500 рецептов, фильтры: исключить аллергены (8), время, сложность, способ, категория; у ингредиентов есть id товаров |
| `vkusvill_cart_link_create` | ссылка `vkusvill.ru/?share_basket=…`, до 20 позиций |

## Что может

1. **Рецепт → корзина.** Рецепт с фильтрами → id товаров из ингредиентов → ссылка.
2. **Список покупок текстом → корзина.**
3. **Подбор по составу и КБЖУ**: максимум белка, без сахара, без свинины и т. п.
4. **Помощник в магазине**: штрихкод → состав и рейтинг; нет товара → аналоги.
5. **Магазины**: по метро, часам работы, особенностям (кафе, пекарня, сбор батареек…).
6. **Скидки по карте и «от N шт»** как общий ориентир по сети.
7. **Работает без Chrome и без компьютера пользователя**: из запланированных задач,
   с телефона.

## Что не может

- Не знает адрес и магазин, не отдаёт остатки: корзина по ссылке может собраться
  не полностью, это видно только на сайте.
- Не видит аккаунт: нет «6 скидок», Любимого продукта, промокодов, истории, чеков.
- Не видит зелёные ценники и выборку «Скоро исчезнут с полок».
- Цены общие, без персональных. При открытии ссылки сайт пересчитает их сам,
  в том числе применит персональные скидки, если товар в них входит.
- Не оформляет и не оплачивает.

## Как работает на практике

- Лимит частоты: 22.09 `products_search` и `product_details` отвечали 429
  «Превышен лимит запросов» с первого запроса дня и дольше 15 минут, а `recipes`,
  `product_analogs`, `shops` в это время работали. 19.09 ~20 запросов подряд прошли.
  Правило срабатывания неизвестно.
- Ответы большие (скидки, магазины — сотни килобайт): брать `mode=custom` с нужными
  полями, разбирать скриптом.
- По умолчанию `vvonly=1` — только товары бренда ВкусВилл; для полного ассортимента
  передавать `vvonly=0`.

## Роль рядом с Chrome

MCP решает, **что купить** (рецепты, состав, КБЖУ, аналоги, штрихкод).
Chrome решает, **где, почём и есть ли** (адрес, остатки, все скидки, корзина).
Цены пользователю показывать из Chrome; цены MCP — только с пометкой «общая по сети».
При 429 от MCP — брать данные из Chrome; без Chrome — MCP и ссылка на корзину.
